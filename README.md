## Habbits

**Tracker** - это iOS-приложение для создания, отслеживания и редактирования ежедневных привычек и единичных событий. Пользователь может создавать трекеры привычек, выбрав название, цвет, а также настроить повторение по дням недели и отметить важные привычки, как избранные. Трекеры распределяются по разным категориям, есть возможность закрепления привычки.

## Возможности

- Формирование привычек и событий с созданием имени, цвета и эмодзи
- Создание расписания для отслеживания привычек и событий
- Закрепление наиболее значимых трекеров
- Классификация по категориям
- Возможность редактирования созданных трекеров
- Ведение статистики

## Стек

- **Язык**: Swift
- **UI**: UIKit
- **Архитектура**: MVVM
- **Хранение**: Core Data
- **Минимальная iOS**: 13.4+
